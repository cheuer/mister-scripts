# copy-sfc

Intended to be compatible with the romloader.yaml configuration file from [tcprescott/romloader](https://github.com/tcprescott/romloader), this script will copy a .sfc file to the appropriate location on your MiSTer, and launch it in the SNES core.

Copy romloader_example.yaml to romloader.yaml and edit the configuration to match your MiSTer setup and add entries for your MSU packs. Then run copy_sfc.bat with the path to a .sfc file as an argument, or set Windows to automatically open .sfc files with copy_sfc.bat.
